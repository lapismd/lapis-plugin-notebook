# Plugins

The standalone catalog groups each externally distributed plugin beneath its
plugin name. Notebook is the package's only plugin.

## Requirements

| ID | Requirement |
| --- | --- |
| LPN-SPEC-010 | Canonical plugin specification chapters and their Storybook mirrors MUST use the `Plugins / <Plugin>` hierarchy and matching relative paths. Storybook story titles MUST use `Plugins/<Plugin>/*`. |
